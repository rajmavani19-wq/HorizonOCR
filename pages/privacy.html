Security, Data Rights & Legal Privacy

Privacy Policy

Comprehensive privacy policy detailing data protection, multi-tenant document isolation, cryptographic security, and technical architecture disclosure for HorizonOCR.

1. Multi-Tenant Document Data Isolation & Ownership

HorizonOCR is engineered with strict account-scoped data isolation. Every document uploaded to our processing pipeline—including multi-page PDFs, high-resolution PNG scans, extracted Markdown text, and binary image BLOBs—is strictly bound to your authenticated user account ID (user_id).

You retain 100% intellectual property ownership over all uploaded source documents and generated deliverables. Other registered users cannot access, view, or query your document history, extracted tables, or stored images.

2. SQLite Binary BLOB Storage & Image Security

User profiles, password hashes, processing timing metrics, document metadata, and extracted graphics are stored in a secure SQLite database (horizonocr.db):

  • Binary BLOB Persistence: Embedded PDF images and diagrams are converted to web-standard 24-bit PNG format and stored as binary BLOB data inside the document_images table.
  • Session Scoped Serving: Image assets are served via GET /api/images/<img_name>, which strictly validates session ownership against user_id to block cross-account data leaks.
  • CMYK Color Normalization: Strips print color profiles and converts complex CMYK/JPX graphics to standard RGB PNGs using Pillow (PIL.Image) before persistence.

3. Password Hashing & Session Cookie Security

User credentials and session state are secured using industry-standard cryptography:

  • Cryptographic Password Hashing: User passwords are encrypted using PBKDF2 with SHA-256 (via werkzeug.security) before storage in the database. Plaintext passwords are never stored or logged.
  • Encrypted HTTP-Only Session Cookies: Authentication state is managed via encrypted, signed HTTP-only session cookies with SameSite enforcement.
  • CSRF Token Validation: All state-mutating requests require cryptographic Double-Submit CSRF tokens verified via /api/csrf.
  • Zero Third-Party Trackers: We do NOT use third-party tracking cookies, Google Analytics scripts, or cross-site behavioral trackers.

4. Temporary File Scrubbing & Data Deletion

Temporary file caches generated during PDF rasterization and ONNX OCR inference are created in isolated temporary directories (tempfile.mkdtemp) and are immediately scrubbed and purged upon task completion.

You maintain full control over your document history. You may delete past document records, clear cached outputs, or purge your account data at any time via your Dashboard.

5. Anti-Selling & Non-Training Guarantee

We strictly pledge that your uploaded documents, extracted Markdown text, and mathematical formulas will NEVER be sold, leased, or shared with third-party data brokers or advertising networks. Furthermore, your data is never used to train public AI models.
