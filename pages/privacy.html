Security, Data Rights & Legal Privacy

Privacy Policy

Comprehensive legal privacy policy detailing data protection, multi-tenant SQLite database isolation, user ownership rights, and full development methodology.

1. Multi-Tenant Document Data Isolation & Ownership

HorizonOCR enforces strict account-scoped document data isolation. Every document uploaded to our processing pipeline—including multi-page PDFs, PNGs, JPGs, WEBP files, extracted Markdown text, and binary image BLOBs—is strictly bound to your authenticated user account ID (user_id).

You retain 100% intellectual property ownership over all uploaded source documents and generated deliverables. Other registered users cannot access, view, or query your document history, extracted tables, or stored images.

2. SQLite Binary BLOB Storage & Image Security

User profiles, password hashes, processing timing metrics, document metadata, and extracted graphics are stored in a secure SQLite database (database.db):

  • Binary BLOB Persistence: Embedded PDF images and diagrams are converted to web-standard 24-bit PNG format and stored as binary BLOB data inside document_images.
  • Session Scoped Serving: Image assets are served via GET /api/images/<img_name>, which validates session ownership to block cross-account data leaks.
  • CMYK Color Normalization: Strips print color profiles and converts complex CMYK/JPX graphics to RGB PNGs using Pillow (PIL.Image) before persistence.

3. Password Hashing & Session Cookie Security

User credentials and session state are secured using industry-standard cryptography:

  • Cryptographic Password Hashing: User passwords are hashed using PBKDF2 with SHA-256 before storage in SQLite users.
  • Encrypted HTTP-Only Session Cookies: Authentication state is managed via encrypted HTTP-only session cookies (session['user_id']).
  • Zero Third-Party Trackers: We do NOT use third-party tracking cookies, Google Analytics scripts, or cross-site behavioral trackers.

4. Temporary File Scrubbing & User Data Deletion

Temporary file caches generated during PDF rasterization are immediately scrubbed from server memory upon completion of the OCR pipeline.

You maintain full control over your document history. You may delete past document records, clear cached outputs, or purge your account data at any time via your Dashboard profile settings.

5. Anti-Selling & Non-Training Guarantee

We strictly pledge that your uploaded documents, extracted Markdown text, and mathematical formulas will NEVER be sold, leased, or shared with third-party data brokers or advertising networks. Furthermore, your data is never used to train third-party AI models.
