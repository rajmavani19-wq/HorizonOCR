Core Technology

Architectural Highlights

One-Shot Long Horizon

Maintains context coherence across 32,768 tokens, rendering multi-page PDFs directly into continuous Markdown structure.

SGLang & FlashAttention-3

Leverages custom logit processors (`DeepseekOCRNoRepeatNGramLogitProcessor`) to prevent loop repeating in dense OCR tasks.

Gundam & Base Crop Tiling

Dynamic crop tiling at 1024 base resolution with 640 sub-tiles for detailed table schemas and handwritten math formulas.

Secure SQLite Database

Persists user profiles and document history securely with hashed passwords and session management.

Multi-Format Structured Export

Export parsed document outputs directly as Markdown (.md), raw code, or structured AST JSON.

Real-Time 3-Panel Workspace

Monitor original document preview, raw text streaming, and rendered layout visualization simultaneously.
