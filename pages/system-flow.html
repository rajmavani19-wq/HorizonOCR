Frontend User Experience & Visual Flow

HorizonOCR Frontend System Flow

A step-by-step visual breakdown explaining the complete user journey across the HorizonOCR single-page application—from initial website landing to 3-panel workspace streaming, KaTeX formula rendering, and 60fps lockstep scroll synchronization.

STAGE 01 • LANDING PAGE ENTRY 01

Website Entry & SPA Router Handshake

When the user opens the web application, the lightweight Vanilla JS single-page router initializes instantly. It renders the modern monochrome landing page, triggers Lucide vector icons, and configures navigation routes without reloading the browser.

Vanilla JS SPA Router Lucide SVG Icons Glassmorphic CSS System Space Grotesk Typography
STAGE 02 • USER AUTHENTICATION 02

Registration Guard & Login Navigation

Unauthenticated visitors clicking "Try Playground" are guided to the Registration view (authView). Upon entering credentials, client-side input validation runs, switching the UI state to authenticated mode and unlocking the user workspace header.

Client Auth Guard Form Validation Dynamic Navbar Switcher User Badge UI
STAGE 03 • DOCUMENT FILE INTAKE 03

Interactive Drag & Drop Upload Zone

On the Dashboard (uploadView), users drag and drop PDF or PNG document files. The frontend validates format integrity, checks the 50MB file size boundary, counts PDF pages, and triggers smooth drop animations.

HTML5 Drag & Drop File Format Validation 50MB Client Cap Drop Animations
STAGE 04 • 3-PANEL WORKSPACE LAUNCH 04

3-Panel Visual Workspace & Canvas Renderer

The app transitions to the Workspace (ocrView). Panel 1 renders the PDF page canvas via PDF.js with laser scan animation beams and spatial bounding box overlays representing detected document regions.

PDF.js Canvas Laser Scan Beam Spatial Overlays Page Controls & Zoom
STAGE 05 • STREAMING & MARKDOWN PARSING 05

Real-Time Typewriter Cadence & KaTeX Rendering

Panel 2 streams raw OCR text progressively according to user speed preferences (Slow/Medium/Fast). Simultaneously, Panel 3 parses Markdown structure via marked.js, renders LaTeX math formulas using KaTeX ($$ ... $$), and displays formatted image tags.

Typewriter Cadence Engine marked.js Parser KaTeX Math Formula Vector AST View Switcher
STAGE 06 • LOCKSTEP SCROLL SYNC 06

0ms 60fps Lockstep Synchronized Scrolling

Panel 2 (Raw OCR Stream) and Panel 3 (Layout Visualization) execute a frame-locked requestAnimationFrame() scroll algorithm. Utilizing scroll-behavior: auto, both panels maintain 1:1 proportional scroll alignment with zero UI delay.

0ms Auto Scroll requestAnimationFrame Sync Bidirectional Scroll Ratio 60fps Lockstep Alignment
STAGE 07 • HISTORY EXPORT & LOGOUT 07

Document History Review, Export & Logout

Users can inspect past document parsing runs in the Dashboard history table, copy output text, or export structured .md files. Clicking "Logout" clears active UI user state and smoothly redirects back to guest mode.

Dashboard History UI One-Click Text Copy Markdown .md Export Guest Reset Router
