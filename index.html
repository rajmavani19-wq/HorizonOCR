Production safeguards where they matter.

Request validation

The service accepts only approved file extensions, checks file size before extraction, verifies PDF and image integrity, and limits page count and image pixels to keep synchronous processing predictable.

Session protection

Password hashes are handled by Werkzeug. Session cookies are HTTP-only and secure in production; every state-changing API request requires a verified CSRF token and allowed origin.

Account isolation

Documents and extracted image assets are stored and retrieved through account-scoped database queries. A signed-in user cannot retrieve another workspace’s private artifacts.

Abuse & resource controls

Sensitive endpoints carry request limits and document processing runs in an isolated temporary directory that is removed after every request. An edge rate limiter remains recommended for multi-instance protection.

1. 3-Panel Visual Workspace Layout

The HorizonOCR frontend interface provides an intuitive 3-panel workspace designed for real-time document review:

  • Panel 1 (Input Document Viewport): Interactive PDF canvas and document preview with page navigation, zoom, laser scan animation beam, and spatial bounding box overlays.
  • Panel 2 (Raw OCR Output Stream): Real-time monospaced typewriter stream showing raw text, list items, GitHub-Flavored Markdown tables, and formatted image tags.
  • Panel 3 (Layout Visualization Screen): Rich HTML rendered view parsing Markdown structure, mathematical formulas, and embedded image assets in real time.

2. Zero-Delay 60fps Lockstep Scroll Engine

Panel 2 and Panel 3 feature a frame-locked scroll synchronization algorithm that keeps both panels locked in 1:1 proportional alignment:

  • 0ms Instant Transition: Utilizes scroll-behavior: auto to eliminate CSS animation queue delay during rapid text updates.
  • requestAnimationFrame Synchronization: Recalculates scroll height ratios after DOM reflow to guarantee zero visual lag.
  • Bidirectional Manual Scroll: Allows users to scroll either panel manually while automatically keeping the adjacent panel locked in proportional scroll sync.

3. Frontend Markdown, KaTeX Math & Image Formatting

The frontend rendering pipeline transforms raw OCR streams into crisp visual layouts:

  • KaTeX Mathematical Equations: Automatically renders inline ($ ... $) and block equation ($$ ... $$) LaTeX delimiters into vector equations.
  • Custom Image Tag Pre-processing: Pre-processes custom tags (e.g., ![Image1 | filename.png]) into interactive image elements inside Panel 3.
  • Tab View Switcher: Instantly toggles between standard Rendered HTML view and structured AST JSON tree view.

4. Design System & SPA Navigation

Built with pure Vanilla JavaScript and a custom Vanilla CSS design system:

  • Ultra-Monochrome Dark Aesthetic: High-contrast black background palette (#050507), subtle glassmorphic cards (backdrop-filter), and Space Grotesk typography.
  • Zero Framework Overhead: Fast single-page application (SPA) router ensuring sub-millisecond view transitions and light bundle memory footprint.
  • Lucide Vector Icons: Crisp, lightweight SVG icon system integrated seamlessly across all workspace panels and navigation controls.

Common Questions & Answers

What document formats and file size limits are supported?
HorizonOCR natively supports multi-page PDF documents (up to 500 pages per file) and high-resolution PNG image scans. The maximum upload file size limit is 50MB per file.
How does HorizonOCR ensure 100% document privacy?
All documents and extracted graphics are bound strictly to your authenticated user_id. Temporary rasterization files are immediately purged from server memory upon OCR completion. Your documents and extracted data are never sold or used to train third-party AI models.
How does the micro-text super-resolution engine work?
Our multi-scale DBNet vision detector identifies even faint text contours. Small bounding boxes (such as 6pt–8pt footnotes, serial codes, or subscripts) are scaled with Bicubic interpolation to a normalized height of 32px+ before recognition to guarantee maximum accuracy.
Can HorizonOCR be deployed in a private air-gapped or on-premises environment?
Yes. HorizonOCR is container-ready (Docker / Gunicorn / SQLite WAL) and can run on air-gapped CPU or NVIDIA CUDA GPU servers with zero external internet dependencies. Reach out via the contact form for custom deployment guidance.
Security, Data Rights & Legal Privacy

Privacy Policy

Comprehensive privacy policy detailing data protection, multi-tenant document isolation, cryptographic security, and technical architecture disclosure for HorizonOCR.

1. Multi-Tenant Document Data Isolation & Ownership

HorizonOCR is engineered with strict account-scoped data isolation. Every document uploaded to our processing pipeline—including multi-page PDFs, high-resolution PNG scans, extracted Markdown text, and binary image BLOBs—is strictly bound to your authenticated user account ID (user_id).

You retain 100% intellectual property ownership over all uploaded source documents and generated deliverables. Other registered users cannot access, view, or query your document history, extracted tables, or stored images.

2. SQLite Binary BLOB Storage & Image Security

User profiles, password hashes, processing timing metrics, document metadata, and extracted graphics are stored in a secure SQLite database (horizonocr.db):

  • Binary BLOB Persistence: Embedded PDF images and diagrams are converted to web-standard 24-bit PNG format and stored as binary BLOB data inside the document_images table.
  • Session Scoped Serving: Image assets are served via GET /api/images/<img_name>, which strictly validates session ownership against user_id to block cross-account data leaks.
  • CMYK Color Normalization: Strips print color profiles and converts complex CMYK/JPX graphics to standard RGB PNGs using Pillow (PIL.Image) before persistence.

3. Password Hashing & Session Cookie Security

User credentials and session state are secured using industry-standard cryptography:

  • Cryptographic Password Hashing: User passwords are encrypted using PBKDF2 with SHA-256 (via werkzeug.security) before storage in the database. Plaintext passwords are never stored or logged.
  • Encrypted HTTP-Only Session Cookies: Authentication state is managed via encrypted, signed HTTP-only session cookies with SameSite enforcement.
  • CSRF Token Validation: All state-mutating requests require cryptographic Double-Submit CSRF tokens verified via /api/csrf.
  • Zero Third-Party Trackers: We do NOT use third-party tracking cookies, Google Analytics scripts, or cross-site behavioral trackers.

4. Temporary File Scrubbing & Data Deletion

Temporary file caches generated during PDF rasterization and ONNX OCR inference are created in isolated temporary directories (tempfile.mkdtemp) and are immediately scrubbed and purged upon task completion.

You maintain full control over your document history. You may delete past document records, clear cached outputs, or purge your account data at any time via your Dashboard.

5. Anti-Selling & Non-Training Guarantee

We strictly pledge that your uploaded documents, extracted Markdown text, and mathematical formulas will NEVER be sold, leased, or shared with third-party data brokers or advertising networks. Furthermore, your data is never used to train public AI models.

6. Document Processing Lifecycle, In-Memory Isolation & Automatic Purging

HorizonOCR employs an ephemeral, in-memory processing pipeline designed to minimize data exposure throughout the OCR extraction lifecycle:

  • Single-Pass In-Memory Execution: Uploaded PDF and PNG files are parsed directly in memory buffers. Native digital PDF characters, layout bounding boxes, and structural tables are extracted without writing intermediary unencrypted text files to disk.
  • Zero Cloud Telemetry & Private Model Hosting: All deep-learning vision models (DBNet text detector, line recognizer) execute locally within the secure runtime environment. No document payloads or OCR tokens are sent to external third-party cloud APIs.
  • User-Controlled Data Deletion: You retain complete authority over your document history. You may delete past document records, clear cached outputs, or purge your account data at any time via your Dashboard.
  • Secure Binary Image Retrieval: Extracted document graphics stored in the database are served exclusively through session-validated endpoints with cryptographic origin verification, preventing unauthorized cross-user access.
